# 2026-10-06 — Always-on personal agents

## [[moc-personal-agents]] — Guide: always-on personal AI agents

What separates OpenClaw, Hermes, Grok Bot, Gemini Spark, Claude Cowork, Meta Muse and OpenAI Dots from coding agents, with a comparison table and how to choose.

## [[openai-dots]] — OpenAI Dots

OpenAI's always-on agents, launched at DevDay on 29 Sept: each Dot gets its own cloud computer, runs on GPT-6 Astra, and you message it from ChatGPT, Slack or Teams.

## [[hermes-agent]] — Hermes Agent

Nous Research's open-source, self-improving personal agent (~251k ⭐), now the open-source default after OpenClaw's hype faded.
