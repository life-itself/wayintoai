# Amp: use your Claude plan

The Amp coding agent now runs on your Claude Pro or Max subscription, not just pay-as-you-go API credits.

![Use Your Claude Plan in Amp](https://screenshotit.app/https://ampcode.com/news/use-your-claude-plan)

## Links

- **Announcement**: https://ampcode.com/news/use-your-claude-plan (10 Oct 2026)
- **Earlier ChatGPT subscription support**: https://ampcode.com/news/subscriptions (18 Jul 2026)

## Overview

Until now, using Claude in Amp meant paying for the API, which is much dearer than a Claude subscription. Amp now has a "Mode > Claude Code" option: link your Claude account and the thread runs on your plan. Amp says it is "free and available for everyone now". Under the hood it uses the Claude Agent SDK instead of Amp's own agent loop, but keeps Amp's thread sharing, multiplayer and runners.

Amp already let you link a ChatGPT subscription (since July), so you can now use Amp on either of the two big consumer plans.

## Why interesting

Subscriptions are much cheaper than API billing for heavy agent use, and that has kept many people inside Claude Code and Codex. Removing it makes Amp worth trying again. See [[amp-coding-agent-is-dead]] for Amp's earlier change of direction.
