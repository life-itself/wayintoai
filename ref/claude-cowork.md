# Claude Cowork

Anthropic's "Claude Code for the rest of your work": point Claude at your files and tools, describe the outcome, and it plans, acts and reports back. It can also run on a schedule, or in the cloud with your laptop closed.

![Claude Cowork](https://screenshotit.app/https://claude.com/product/cowork)

## Links

- **Product page**: https://claude.com/product/cowork
- **Launch post**: https://claude.com/blog/cowork-research-preview (12 Jan 2026)

## Overview

Cowork brought the Claude Code agent loop to non-coders. It reads and writes files in folders you choose, uses connected tools, drives a built-in browser, and shows each step so you can steer it. It isn't a messaging-first assistant like [[openclaw]] or [[hermes-agent]]. It got there by adding features: [[claude-dispatch]] lets you hand it tasks from your phone, and scheduled tasks and cloud runs keep it working while you're away.

## Timeline

- **12 Jan 2026**: research preview in Claude Desktop (macOS), Max only
- **16–23 Jan**: extended to Pro, then Team and Enterprise
- **10 Feb**: Windows
- **17 Mar**: [[claude-dispatch]] (assign tasks from your phone)
- **9 Apr**: general availability on desktop
- **7 Jul**: web and mobile betas

## Availability

Included in all paid Claude plans: Pro ($20/mo), Max ($100 / $200), Team, Enterprise.

## Why Interesting

It's Anthropic's version of the personal-agent idea, built outward from the coding agent rather than from a chat app. It launched before OpenClaw's viral week, so it's a parallel track, not a reaction. Dispatch was the part that answered OpenClaw directly.
