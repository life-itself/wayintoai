# AI browsers: a map

**TL;DR:** An *AI browser* puts an agent inside the web browser, so it can read pages and act on sites logged in as you. There are three kinds: new browsers built around an agent, AI added to the big existing browsers, and agents that drive your browser through an extension. For most people the agent they already pay for (Claude, ChatGPT) now does enough; a dedicated AI browser earns its place for long or scheduled web workflows.

## Why a browser at all?

Much knowledge work happens in websites with no API: CRMs, job boards, booking systems, admin panels. The browser already holds your logins, so an agent working there can use any site as you, and you can watch and take over. The alternative is connectors (APIs, MCP), which are faster and more reliable but only exist for some services.

## The options

| Kind | Examples | Notes |
|---|---|---|
| New AI-first browsers | Perplexity Comet, OpenAI ChatGPT Atlas, Dia (The Browser Company, now Atlassian), Opera Neon, [[polar-browser]] | Switch browsers to get the agent |
| AI in existing browsers | Gemini in Chrome, Copilot Mode in Edge | Built-in; least effort |
| Agent drives your browser | Claude in Chrome (extension), ChatGPT agent mode | Use the agent you already have |

*This list reflects our entries plus well-known launches since 2025; it is not exhaustive. Add entries as we log them.*
