# AI Design Skills (elayadesign)

A small, popular repo of design skills for coding agents. So far it holds one: `landing-page-design`, which builds a landing page from intake questions through structure, conversion copy and a visual system.

![AI Design Skills on GitHub](https://screenshotit.app/https://github.com/elayadesign/ai-design-skills)

## Links

- **GitHub**: https://github.com/elayadesign/ai-design-skills (MIT, ~11k stars at 28 Oct 2026)

## Overview

Each skill is a self-contained folder you copy into your project, e.g. `.claude/skills/` for Claude Code. It also works with Cursor, Codex (`AGENTS.md`), Windsurf, Cline and Claude.ai Projects. More skills are promised.
